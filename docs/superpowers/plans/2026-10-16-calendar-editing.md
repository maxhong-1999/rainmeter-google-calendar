# 달력 편집 구현 계획

목표: 또렷한 글씨와 달력 내부 구글 일정 추가·삭제를 제공한다.

- [ ] 기본 글꼴과 그림자·상세 크기를 조정하고 스타일 주소에 버전을 붙인다.
- [ ] calendar-editor.mjs(편집 화면)에 구글 일정의 날짜별 변환, 입력 검증, 네이티브 요청 전달과 추가·상세·삭제 대화상자를 검사부터 구현한다.
- [ ] CalendarBridge.ps1(구글 연동 실행기)에 입력 검증, 브라우저 로그인, 사용자 암호화와 구글 호출을 구현한다. 실제 계정 없이 백엔드 검사를 실행한다.
- [ ] calendar.js(기존 화면)에서 연결된 경우만 구글 응답으로 개인 피드를 대체하고 공휴일·주 선택을 유지한다.
- [ ] 빈 요청 파일 생성, 실행 플러그인, 개인정보 배제 목록과 최초 계정 연결 안내를 갱신한다.
- [ ] 모의 응답 브라우저와 전체 검사를 실행하고 코드 검토 후 현재 화면에 적용한다.
- [ ] 배포 파일을 검증하고 사용자 연결 파일이 준비되면 실제 계정 연결을 확인한다.
