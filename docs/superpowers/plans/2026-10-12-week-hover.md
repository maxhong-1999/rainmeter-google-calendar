# 주별 일정 확장 구현 계획

목표: 선택한 주는 자세한 일정을 표시하고 다른 주는 날짜만 남기며 부드럽게 접히게 한다.

구조: `calendar-week-focus.mjs`(주 선택 제어)에 높이·시간 표시·마우스와 키보드 상태를 모은다. `calendar.js`(달력 화면)는 기본 목록과 상세 목록을 만들어 이 제어기에 연결한다. CSS(화면 스타일)가 높이와 투명도를 이어서 전환한다. 외부 라이브러리는 추가하지 않는다.

- [x] `tests/calendar-week-focus.test.mjs`(주 선택 검사)에 6개 높이 합, 유효하지 않은 선택, 종일 및 시간 범위, 진입·이탈 취소 동작을 작성해 실패를 확인한다.
- [x] `weekTracks(week)`(주 높이 계산), `formatEventTime(event, day)`(시간 표시), `createWeekFocusController(grid)`(주 선택 제어)를 구현한다. `grid.style.gridTemplateRows = weekTracks(week)`로 6개 높이를 바꾸고 각 날짜의 `is-week-focused`(선택한 주) 상태를 갱신한다.
- [x] 일정 파서가 종료 시간을 보존하도록 수정한다. 기본 `events.slice(0, 2)`(일정 두 개)와 별도 전체 상세 목록을 렌더링한다. 월 이동은 선택 초기화, 정기 갱신은 선택 유지로 연결한다.
- [x] 기본 높이 317픽셀과 220밀리초 전환, 목록 교차 표시, 날짜별 스크롤, 움직임 줄이기 스타일을 작성한다. `node --test tests/*.test.mjs`(전체 검사)를 실행한다.
- [x] 예시 일정만 제공하는 브라우저에서 실제 마우스 이동으로 높이·내용·빠른 주 이동·이탈·스크롤·월 이동을 확인한다. 코드 검토 뒤 현재 기기의 화면 파일만 백업·교체하고 웹 화면만 다시 불러온다.
- [x] 한국어 및 영문 안내와 배포 목록을 갱신하고 1.3.0 설치 파일을 생성한다. 검증한 코드와 파일의 깃허브 배포를 준비한다.
