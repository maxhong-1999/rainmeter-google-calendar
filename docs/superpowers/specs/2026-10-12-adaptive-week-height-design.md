# 내용에 맞춘 주별 확장 높이

사용자가 고정 172픽셀 확장 때문에 다른 주로 이동할 때 마우스를 과하게 움직여야 한다고 보고했다. 주별 가로줄, 전체 창 크기, 상세 일정 표시와 기존 전환 방식은 유지한다.

기본 주 높이는 52픽셀이다. 선택한 주의 일곱 날짜에서 상세 내용의 실제 높이를 측정해 가장 긴 날짜에 맞춘다. 날짜와 목록 여백 30픽셀을 더하고, 52~108픽셀로 제한한다. 빈 주는 커서 위치 보정이 필요하지 않으면 확대하지 않는다. 다른 다섯 주는 남은 높이를 균등하게 나누므로 최소 40.8픽셀이 남고 날짜를 편하게 선택할 수 있다.

다른 주로 옮길 때는 내용 높이에 더해 커서가 선택한 주 안에 머무르는 데 필요한 최소 높이를 계산한다. 경계 반올림에 대비해 2픽셀 안쪽 여유를 계산한다. 내용이 적은 주로 옮긴 뒤 압축 모션 때문에 커서 아래 날짜가 바뀌는 현상을 방지한다. 키보드 선택은 내용 높이만 사용한다. 마우스가 밖으로 나가거나 화면을 숨기면 위치 보정을 초기화한다.

측정은 목록의 현재 스크롤 높이가 아닌 자식 내용의 실제 높이와 여백을 사용한다. 일정이 줄어든 뒤 다시 갱신했을 때도 높이가 줄어들어야 한다. 많은 일정은 기존처럼 날짜 안에서 스크롤한다. 모션 길이는 220밀리초를 유지한다.

검증은 높이 합·상한·커서 유지 계산 검사와 예시 일정 브라우저 검사로 한다. 빈 주, 한 일정, 긴 제목, 많은 일정, 빠른 이동, 정지한 커서, 일정 수 감소, 키보드·갱신·모션 줄이기를 확인한다. 현재 화면에 적용하고 1.3.1로 배포한다.

현재 레인미터에서 이전 모듈 캐시가 재사용되는 현상을 확인했다. 진입 스크립트와 주 선택 모듈의 주소에 같은 배포 버전을 붙여 새 파일이 로드되도록 한다.
