# 주별 일정 확장 설계

사용자는 주별 가로줄을 선택했고, 제목·시간을 자세히 보여주며 약 0.2초 동안 확장·압축하는 설계에 동의했다.

달력 창은 600×420을 유지한다. 평소에는 6개 주가 각각 52픽셀이고 날짜와 일정 두 개를 표시한다. 주에 마우스를 올리면 해당 주는 172픽셀, 나머지 다섯 주는 28픽셀이 되어 날짜만 남는다. 줄 간격 1픽셀을 포함한 전체 높이는 317픽셀로 동일하다. 요일별 너비도 유지한다.

확장한 주에는 각 날짜의 모든 일정 제목을 줄바꿈해 표시하고 시작·종료 시간 또는 종일 표시를 붙인다. 일정이 많으면 그 날짜의 목록 안에서 스크롤한다. 일정을 임의로 줄이거나 설명·장소까지 새로 추가하지 않는다.

첫 진입은 80밀리초 후 확장하며, 달력 밖으로 나간 뒤 140밀리초 후 기본 상태로 돌아간다. 높이는 220밀리초, 목록 투명도는 140밀리초 동안 전환한다. 움직이는 중 다른 주를 선택하면 현재 높이에서 새 목표로 이어진다. 같은 주의 자식 요소 이동은 다시 시작하지 않는다.

키보드로 날짜를 선택하면 같은 주의 상세 내용을 즉시 표시한다. 방향키로 날짜를 이동하고, 움직임 줄이기 설정에서는 모션을 제거한다. 월 변경과 화면 숨김에서는 선택을 초기화한다. 주기적 일정 갱신에서는 선택한 주를 유지한다.

검증은 상태·시간 표시 테스트, 실제 브라우저의 주 높이·빠른 이동·마우스 이탈·월 이동·스크롤·움직임 줄이기와 실제 레인미터 화면 적용으로 한다. 일정 주소와 계정 설정은 수정하지 않는다.
