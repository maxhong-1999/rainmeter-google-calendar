# 구글 계정 연결과 기존 일정 수정

사용자는 본인 구글 계정을 연결하고 달력 안에서 일정을 편집하도록 요청했다. 기존 1.4.0의 추가·삭제와 계정 연결 실행기를 유지하고 수정 동작을 보완한다.

본인 소유 개인 일정의 상세창에 일정 수정 버튼을 제공한다. 기존 추가창을 재사용해 제목·시작과 종료 날짜·시간·종일 여부를 채운다. 종일 일정의 종료 날짜는 마지막 날로 표시하며 반복 일정은 선택한 회차만 수정한다. 공휴일·참석자 포함·특수 일정은 기존처럼 읽기 전용이다.

구글에는 선택한 달력과 일정 식별값, 조회 시 변경 확인값을 함께 전달한다. 실행기는 대상과 최신 상태를 확인한 뒤 PATCH(변경한 항목만 저장)와 If-Match(동시 변경 방지)를 사용한다. 제목·시작·종료 외 설명·알림·첨부·반복 규칙을 보내지 않는다. 종일과 시간 지정 간 전환 때 반대 종류의 날짜 필드는 명시적으로 비운다.

성공하면 이전 날짜의 일정 카드를 제거하고 새 날짜에 반영한다. 이후 조회가 실패해도 오래된 일정이 다시 나타나지 않는다. 저장 실패 시 입력값과 원래 일정은 유지한다.

계정 연결은 기존 데스크톱 설정 파일과 시스템 브라우저 승인을 사용한다. 사용자 클라우드에는 달력 전용 프로젝트가 없으며 새 프로젝트 생성은 자동 승인 검토에서 거절되었다. 새 프로젝트·연결 설정 생성 승인을 받기 전에는 클라우드 변경을 재시도하지 않는다. 사용자 로그인·승인을 대신했다고 주장하지 않는다. 인증 자료·요청·응답은 공개하지 않는다.

검증은 예시 일정으로 날짜 왕복, 종일 전환, 단일 회차, 오래된 변경값·다른 달력·참석자 보호, 수정 후 조회 실패, 기존 추가·삭제·주 확장을 확인한다. 실제 일정은 자동 검사 목적으로 변경하지 않는다.
