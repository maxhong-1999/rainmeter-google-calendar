# 또렷한 글씨와 구글 일정 추가·삭제

사용자는 글씨를 또렷하게 바꾸고 달력 안에서 구글 캘린더 원본의 일정을 추가·삭제하기를 요청했다. 기존 비공개 일정 피드는 읽기 전용이므로 쓰기 권한 계정 연결을 별도로 제공한다.

글씨는 맑은 고딕을 우선 사용하고 기본 화면의 번지는 4픽셀 그림자를 1픽셀로 줄인다. 날짜와 상세 제목·시간은 조금 키운다. 색상·투명도·적응형 주 높이·모서리 호출은 유지한다.

달력 제목 옆 추가 버튼이나 날짜의 문맥 메뉴에서 해당 날짜의 추가창을 연다. 제목, 시작·종료 날짜와 시간, 종일 여부를 입력한다. 개인 일정 카드를 선택하면 제목·시간과 삭제 버튼을 표시하고 한 번 더 확인한다. 반복 일정은 선택한 회차만 삭제한다. 공휴일과 초대한 참석자가 있는 일정은 읽기 전용으로 표시한다.

구글에 연결하기 전에는 기존 피드가 계속 표시된다. 연결 후에는 선택한 본인 소유 달력의 API(구글 일정 연동) 응답으로 개인 일정 목록을 대체한다. 추가·삭제 성공 후 즉시 다시 조회한다. 실패하면 기존 내용과 입력값을 유지하고 오류를 표시한다.

연결은 데스크톱 앱용 OAuth(계정 연결) 설정 파일을 선택한 뒤 시스템 브라우저에서 진행한다. 임시 로컬 콜백, 무작위 상태 검증과 PKCE(로그인 코드 가로채기 방지)를 사용한다. 권한은 본인 소유 달력의 일정과 달력 목록 조회다. 토큰과 클라이언트 설정은 Windows DPAPI(현재 사용자 암호화)로 보관하고 웹 화면에 전달하지 않는다.

기존 RunCommand(외부 명령 실행) 플러그인과 PowerShell(파워셸)5.1을 사용한다. 웹 요청은 인코딩한 로컬 요청 파일로 전달한다. 작업·입력·대상 경로를 제한한다. 일정 문자열을 레인미터 명령으로 직접 연결하지 않는다. 요청·응답과 인증 자료는 공개·설치 파일에 포함하지 않는다.

검증은 날짜·시간 변환, 명령 인코딩, 쓰기 실패·오래된 응답 처리, 백엔드 입력·암호화·호출 경로, 예시 브라우저의 추가·삭제·확인·공휴일 보호를 포함한다. 실제 계정 인증은 사용자 설정과 로그인 후 확인한다. 검사를 위해 실제 개인 일정을 자동 생성·삭제하지 않는다.
