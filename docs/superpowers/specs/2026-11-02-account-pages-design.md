# 구글 계정 등록용 안내 페이지

사용자가 기존 깃허브 저장소에 무료 안내 페이지를 준비하는 방식을 선택했다. 앞서 제시한 프로그램 소개, 개인정보 처리 안내, 이용 안내를 각각 한 페이지로 만든다.

## 범위

- 홈페이지는 프로그램의 목적, 설치 경로, 일정 조회와 편집 기능, 기기별 계정 연결을 설명한다.
- 개인정보처리방침은 실제 코드가 요청하는 정보, 구글과의 직접 통신, 윈도우 사용자별 인증정보 암호화, 평문 일정 캐시, 연결 해제와 삭제 방법을 구분한다.
- 이용 안내는 기존 공개 소스 이용허락과 구글 연동 조건을 설명한다. 새 결제 기능이나 별도 약정을 만들지 않는다.
- 개인 계정, 이메일, 일정, 비공개 일정 주소, 인증정보는 공개 파일에 넣지 않는다.

## 구성

기존 `docs/` 폴더에 정적 문서 세 개와 공통 스타일을 둔다. 추가 의존성, 외부 글꼴, 분석 도구, 로그인 폼을 사용하지 않는다. 깃허브의 기본 브랜치 문서 폴더를 무료 페이지의 게시 원본으로 지정한다. 안내 사이트만 배포하며 달력 설치 파일과 실행 코드는 변경하지 않는다.

## 확인

내부 링크와 작은 화면의 가독성을 확인하고 기존 자동 검사를 실행한다. 소스 검토와 원격 검사를 통과한 뒤 기본 브랜치에 반영한다. 공개된 세 문서가 정상 응답하는지 확인한 다음 구글 등록 화면에 주소를 넣는다. 홈페이지 소유 확인이나 앱 운영 전환에서 접근 권한이 달라지는 단계는 실제 화면을 확인해 마지막에 승인받는다.
