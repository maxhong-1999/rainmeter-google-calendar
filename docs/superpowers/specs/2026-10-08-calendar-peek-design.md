# 모서리로 달력 호출하기

사용자가 승인한 동작: 화면에 호출 버튼을 두지 않는다. 각 모니터 왼쪽 위 6픽셀 영역에서 400밀리초 머물면 달력이 그 모니터 작업 영역 안에 나타나고, 달력과 모서리를 벗어난 뒤 600밀리초가 지나면 원래 바탕화면 위치로 돌아간다. 전체 화면 앱이 활성화되어 있거나 마우스로 드래그하는 동안에는 호출하지 않는다. 달력 안에서는 월 이동과 일정 확인을 그대로 사용할 수 있다.

현재 기기에 추가 프로그램 설치 없이 동작하도록 Windows PowerShell(윈도우 파워셸) 5.1과 기본 제공 .NET(닷넷)으로 작은 제어기를 실행한다. RunCommand(외부 명령 실행) 플러그인의 숨김 프로세스 수명 관리로 스킨 새로고침·해제 시 제어기가 종료된다. 달력은 언로드하지 않아 일정 갱신이 유지된다.

기본 대기 상태는 바탕화면 표시다. 사용자 설정은 별도 CalendarPeek.ini(달력 호출 설정)에 보관하며 완전 숨김, 모서리 네 곳, 감지 크기와 시간, 전체 화면 차단, 비활성화를 지원한다. 배포 파일에는 기본값만 넣고 업데이트 시 기존 설정을 보존한다. 개인정보 설정과 일정 캐시는 읽거나 배포하지 않는다.

검증: 시간에 따른 호출·닫힘·재진입·차단·모니터 경계·이동 복원과 설정 해석을 실제 제어기 코드로 테스트한다. 기존 전체 테스트와 배포 파일 검사를 실행하고 로컬 스킨에 적용한다. 다른 기기에서 설치할 수 있도록 1.2.0 설치 파일과 한국어 사용 설명을 배포한다.
