개인정보처리방침

시행일: 2026년 11월 2일

이 안내는 공개 소스 프로그램 Rainmeter Calendar(레인미터 달력)와 이 안내 사이트에 적용됩니다. 프로그램의 소스와 변경 이력은 공개 저장소에서 확인할 수 있습니다. 관리 주체는 해당 저장소의 관리자와 기여자이며, 문의는 프로젝트 문제 신고 게시판으로 접수합니다.

요청하는 정보와 사용 목적

  • 달력 목록: 본인 소유 달력을 선택하기 위해 달력의 식별자, 이름, 기본 달력 여부를 조회합니다.
  • 선택한 달력의 일정: 일정 제목, 시작과 종료 시간, 종일 여부, 반복 회차 식별자, 변경 확인값과 수정 가능 여부를 판단하는 정보를 사용합니다. 달력 표시와 사용자가 요청한 일정 추가, 수정, 삭제에 사용합니다.
  • 계정 연결 정보: 구글에서 발급한 접근 토큰과 갱신 토큰, 데스크톱 앱 연결 설정을 사용해 승인받은 계정에 연결합니다. 프로그램에서 구글 비밀번호를 입력받거나 저장하지 않습니다.
  • 기기 설정: 선택한 달력, 색상과 투명도, 호출 방식, 선택한 브라우저 프로필 등의 설정을 기기에 저장합니다.

구글 연결에는 본인 소유 일정 관리 권한과 달력 목록 조회 권한을 요청합니다. 이 정보는 위 기능을 제공하는 데 사용하며 광고, 정보 판매, 인공지능 모델 학습에 사용하지 않습니다. 구글에서 받은 정보의 사용은 구글 API(서비스 연동) 사용자 데이터 정책과 제한적 이용 요건을 따릅니다.

통신과 제삼자 제공

계정 승인은 구글의 로그인 화면에서 진행합니다. 설치된 프로그램은 구글 일정 서비스 및 사용자가 설정한 일정 피드 주소에 직접 요청합니다. 프로그램에는 개인 일정을 개발자 서버로 보내거나 판매하는 기능이 없습니다. 사용자가 일정을 추가하거나 수정 또는 삭제하면 그 요청은 구글 캘린더 원본에 반영됩니다.

이 안내 사이트에는 계정 연결 폼, 일정 업로드 기능, 별도 분석 도구나 광고가 없습니다. 사이트는 깃허브 페이지로 제공되므로 접속 로그 등 호스팅 서비스의 데이터 처리는 깃허브 개인정보처리방침을 따릅니다.

기기에 저장되는 정보

계정 연결 정보는 윈도우의 로컬 앱 데이터 폴더에 현재 윈도우 사용자에게 묶여 암호화된 파일로 저장합니다. 다른 컴퓨터에 복사해 사용하는 방식이 아닙니다.

일정 피드의 다운로드 파일과 구글 연동 요청 및 응답 파일은 달력 스킨 폴더에 저장될 수 있습니다. 이 자료에는 일정 내용이 평문으로 남을 수 있습니다. 비공개 일정 주소와 브라우저 계정 설정도 로컬 설정 파일에 저장됩니다. 이러한 파일은 개인 자료이므로 공개 저장소나 문제 신고 게시판에 올리지 마세요.

연결 정보는 연결을 해제할 때까지, 설정과 일정 캐시는 사용자가 해당 기기의 자료를 삭제할 때까지 남을 수 있습니다. 구글 서버의 원본 일정 보관은 사용자의 구글 계정 설정과 구글 정책에 따릅니다.

연결 해제와 삭제

  1. 달력의 ＋ → 구글 계정 → 이 기기 연결 해제를 누르면 해당 기기의 암호화된 계정 연결 파일을 삭제합니다. 구글 캘린더의 원본 일정은 삭제하지 않습니다.
  2. 구글 쪽 접근 권한도 취소하려면 구글 계정의 연결된 앱 관리에서 이 앱의 연결을 삭제합니다.
  3. 프로그램 사용을 끝내고 기기의 자료도 지우려면 레인미터에서 해당 스킨을 해제한 뒤 달력 스킨 폴더의 일정 캐시, 요청 및 응답 파일, 개인 설정을 삭제합니다. 삭제 전에 필요한 설정을 별도로 보관해 주세요.

문의를 보낼 때 비밀번호, 연결 설정 파일, 인증 토큰, 비공개 일정 주소, 개인 일정 내용은 첨부하지 마세요.

변경 안내

데이터 처리 방식이 바뀌면 이 문서와 시행일을 갱신합니다. 구글 정보의 사용 목적이나 필요한 권한이 달라지는 경우 변경 내용을 알리고 필요한 승인을 다시 요청합니다.
