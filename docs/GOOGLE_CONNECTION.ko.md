# 달력에서 구글 일정 추가·삭제하기

기존 비공개 일정 주소는 조회 전용입니다. 글꼴 개선과 일정 조회는 기존 설정으로 바로 사용할 수 있습니다. 달력 안에서 추가·삭제하려면 최초 한 번 쓰기 권한으로 계정을 연결해야 합니다.

## 최초 연결 설정 만들기

1. [구글 클라우드 콘솔](https://console.cloud.google.com/)에서 본인 프로젝트를 선택하거나 만듭니다.
2. 프로젝트의 Google Calendar API(구글 일정 연동)를 사용 설정합니다.
3. Google Auth Platform(구글 계정 연결 설정)의 **Branding(브랜딩)**에서 앱 이름과 본인 이메일을 입력합니다. 개인 지메일 계정이면 **Audience(대상) → External(외부)**을 선택하고, **Test users(테스트 사용자)**에 연결할 본인 이메일을 추가합니다.
4. **Data Access(데이터 액세스)**에서 본인 소유 일정 관리 권한과 달력 목록 조회 권한을 추가합니다. 검색할 권한 주소는 아래 두 개입니다.

   - `https://www.googleapis.com/auth/calendar.events.owned` (본인 소유 일정 조회·추가·변경·삭제)
   - `https://www.googleapis.com/auth/calendar.calendarlist.readonly` (달력 목록 조회)

5. **Clients(클라이언트) → Create client(클라이언트 만들기)**에서 **Desktop app(데스크톱 앱)**을 선택하고 JSON(연결 설정) 파일을 내려받습니다. 웹 앱·서비스 계정 유형은 사용하지 않습니다. 별도 개발 도구를 설치할 필요는 없습니다.
6. 레인미터 달력의 **＋ → 구글 계정 → 연결 설정 파일 선택**에서 해당 파일을 선택합니다.
7. 열린 시스템 브라우저에서 연결할 계정을 고르고 일정 쓰기와 달력 목록 조회 권한을 허용합니다. 완료하면 브라우저 창을 닫고 달력으로 돌아옵니다.
8. **편집할 달력**에서 사용할 본인 소유 달력을 선택합니다. 다른 기기에서는 해당 기기에서 따로 연결합니다.

설정 파일이나 비공개 일정 주소를 이슈·채팅에 올리지 마세요. 저장된 연결 정보는 현재 윈도우 사용자에게 묶여 암호화되므로 다른 컴퓨터에 복사해서 사용하지 않습니다. 테스트 상태의 외부 앱은 구글 정책에 따라 다시 로그인을 요구할 수 있습니다.

공식 절차: [데스크톱 앱 자격 증명 만들기](https://developers.google.com/workspace/calendar/api/quickstart/python#authorize_credentials_for_a_desktop_application), [사용하는 권한의 의미](https://developers.google.com/workspace/calendar/api/auth), [데스크톱 앱 계정 연결](https://developers.google.com/identity/protocols/oauth2/native-app).

## 사용

- 제목 옆 **＋** 또는 날짜의 **마우스 오른쪽 버튼**으로 일정 추가창을 엽니다.
- 제목, 시작·종료 날짜와 시간을 입력해 **구글 캘린더에 저장**합니다. 시간은 한국 시간입니다. 종일 일정의 종료 날짜는 마지막 날을 뜻합니다.
- 개인 일정 카드를 선택하고 **일정 삭제 → 삭제 확인**을 누릅니다. 반복 일정은 선택한 회차만 삭제합니다.
- 공휴일과 참석자가 있는 일정은 이 화면에서 삭제하지 않습니다. 해당 일정은 구글 캘린더에서 관리합니다.
- 구글에 연결하면 선택한 달력을 직접 조회하므로 저장 후 비공개 피드 갱신을 기다리지 않아도 됩니다. 연결을 해제하면 기존 비공개 피드 조회로 돌아갑니다.

## 문제 해결

- 연결 파일 오류: 데스크톱 앱용 파일인지 확인합니다.
- 연결 권한 오류: 일정 쓰기·달력 목록 권한, 테스트 사용자 등록, 일정 연동 사용 설정을 확인하고 다시 연결합니다.
- 오래된 일정 오류: 다른 곳에서 바뀐 일정이므로 새로고침한 뒤 다시 선택합니다.
- 요청·응답 파일은 실행 중에만 쓰는 로컬 자료입니다. CalendarBridge.ini(요청), CalendarBridgeResponse.json(응답)과 임시 응답을 공개하거나 설치 파일에 추가하지 마세요.
